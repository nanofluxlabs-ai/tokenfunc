# 概览页「每日消耗汇总」表格列间距与占比轨道可见性

- 日期：2026-11-22
- 分支：main
- PR：
- 关键 commit：

## 背景

用户反馈：控制台 › 常规 › 概览 的「每日消耗汇总」表格中，「Token」与「主力模型」两列文字挨在一起；占比进度条在 0% 时看不清。

## 变更

- 前端 `features/dashboard/components/personal/daily-summary-table.tsx`：
  - 「主力模型」列表头和单元格加 `ps-10` 左侧留白（保持列顺序不变，用户选定）；
  - 占比进度条轨道由 `bg-muted` 改为 `bg-foreground/10`。

## Bug 根因

- 表格除「占比」外无列宽，自动布局下右对齐的 Token 列与左对齐的主力模型列在列边界两侧相贴，中间只有单元格内边距。
- 卡片底色与 `bg-muted` 几乎相同，进度条无填充时轨道与背景融为一体。

## 验证

- `bun check -b` 无类型错误；`oxlint`、`oxfmt --check` 该文件通过。
- 浏览器（5173 → API 3010，root）暗色主题：主力模型列与 Token 列明显分开，0% 行可见灰色轨道。

在工具里配好了却连不上？选择你用的工具，把你在工具里填的地址粘贴进来，点「开始检查」，逐项告诉你卡在哪一步、该怎么改。

:::self-check
:::

## 每一步检查什么

| 步骤          | 检查内容                                          | 常见问题                                                                       |
| ------------- | ------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1. 地址写法   | 你填的地址是否符合这个工具的要求，不发请求        | `/v1` 多写或少写、填成了完整接口路径、地址不是本站                             |
| 2. 连通与密钥 | 用你的密钥请求模型列表                            | 网络或代理不通；密钥无效、过期或自身额度用完                                   |
| 3. 模型权限   | 所选模型是否在这把密钥的可用列表里                | 模型名拼错；密钥分组不含该模型；密钥限制了可用模型                             |
| 4. 实际调用   | 按工具使用的协议发一次只生成极少 Token 的真实请求 | 余额不足；模型暂无可用渠道；模型不支持该协议（如 Codex 需要的 Responses 接口） |

## 说明

- 检查使用你名为 `default` 的密钥（没有则用最近创建的一把）。如果工具里填的是另一把密钥，结果只能说明本站与模型正常，请到 [API 密钥](/keys) 核对那把密钥的状态和额度。
- 第 4 步会产生一次真实调用，扣除极少的余额，可以在控制台「使用日志」中看到这条记录。
- 第 1 步只检查地址写法；后续步骤直接请求本站的标准地址，所以即使地址写错，也能继续检查密钥和模型。
- 全部通过但工具仍然报错时，按 [常见问题与排错](/docs/faq) 对照工具给出的报错信息排查，或回到对应的工具教程逐项核对配置。

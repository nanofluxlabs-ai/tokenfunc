先用下面的命令确认密钥和地址本身没问题，再去排查工具配置。能返回模型列表，说明密钥有效、网络可达，问题出在工具的配置上。

:::tabs
@tab macOS / Linux

```bash
curl {{baseUrl}}/v1/models -H "Authorization: Bearer {{apiKey}}"
```

@tab Windows

```powershell
Invoke-RestMethod -Uri "{{baseUrl}}/v1/models" -Headers @{ Authorization = "Bearer {{apiKey}}" }
```
:::

## 按报错查原因

| 报错                                 | 常见原因                                               | 处理办法                                                |
| ------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------- |
| `401` 无效的令牌                     | 密钥复制不全、多了空格；密钥已删除、过期或自身额度用完 | 到 [API 密钥](/keys) 核对状态和剩余额度，重新复制       |
| `403` 该令牌无权访问模型             | 密钥设置了可用模型，或所在分组不含该模型               | 在密钥设置里放开该模型，或换一个分组的密钥              |
| `403` 用户额度不足                   | 账户余额不足                                           | 到「钱包」充值，充值后立即恢复                          |
| `404` Not Found                      | 地址里 `/v1` 多写或少写了                              | 对照工具教程检查地址写法，见 [基础概念](/docs/concepts) |
| `503` 无可用渠道 / `model_not_found` | 模型名写错，或该模型暂时不可用                         | 从 [模型广场](/pricing) 复制模型名；换一个模型再试      |
| `429`                                | 请求太频繁                                             | 降低并发，稍后重试                                      |
| `413`                                | 请求体太大（通常是图片或文件过大）                     | 压缩图片，或改用图片链接                                |
| 超时、长时间无响应                   | 生成内容过长或网络不稳定                               | 开启流式输出；检查代理设置                              |

更多状态码和重试建议见 [错误码](/docs/api-errors)。

## 常见问题

### 地址到底带不带 /v1？

看工具用的协议：OpenAI 兼容的工具带 `/v1`，Anthropic 协议的工具（如 Claude Code）不带。每篇工具教程都写明了，拿不准就看 [选择接入方式](/docs/tools-overview) 里的总表。

### 模型广场里有这个模型，为什么调用说没有权限？

模型广场列出的是全站模型。密钥能用哪些模型，取决于密钥所在的分组和密钥上设置的模型限制。调用 [模型列表](/docs/api-models) 接口，返回的才是这把密钥实际能用的模型。

### 工具里能看到回复，但用量和扣费在哪里看？

控制台的「使用日志」里逐条记录了每次请求的模型、Token 数和费用。

### 余额充足，为什么还提示额度不足？

密钥本身可以设置额度上限，密钥额度用完时也会被拒绝。到 [API 密钥](/keys) 查看这把密钥的剩余额度，调高或改为不限额度。

### 换了网络或服务器后调用失败？

如果密钥设置了 IP 白名单，新的出口 IP 不在白名单里就会被拒绝。在密钥设置里更新白名单。

### 工具提示「中转服务风险」或类似提醒？

部分工具（如 WorkBuddy）检测到非官方地址时会弹出提醒，这是工具自身的提示，确认地址是 `{{baseUrl}}` 即可继续使用。

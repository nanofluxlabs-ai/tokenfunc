# 文档中心侧栏整理：API 说明页加图标、工具概览改名、拆掉基础概念页

- 日期：2026-10-31
- 分支：main
- PR：
- 关键 commit：

## 背景

用户反馈三处侧栏问题：API 参考组里鉴权、错误码没有图标，和带 GET/POST 标签的接口页对不齐；工具组第一项「选择接入方式」名字不合适；「基础概念」单独一页很别扭，且「常见问题与排错」与「错误码」内容有重复。

## 变更

- 侧栏：同组有请求方法标签时，没有方法的说明页在同一列放同宽图标（鉴权用钥匙、错误码用警告三角），标题与接口页对齐。
- 工具组第一项改名「概览 / Overview」，站内链接文字改为「工具接入概览 / Tool integration overview」。没有用「快速开始」，避免与开始使用组第一项撞名。
- 拆掉「基础概念」页（中英文）：接口地址 `/v1` 写法表、密钥保管、分组、模型名并入快速开始对应步骤；计费并入常见问题「怎么计费？用量和扣费在哪里看？」。没有整页并进常见问题：这些是接入前要知道的内容，放在出错后才看的页面里第一次接入时看不到。旧地址 `/docs/concepts` 由未知页面回落到快速开始。
- 错误码页状态码表的「常见原因」列改为「含义」：错误码页讲含义与是否重试，原因与处理办法归常见问题，两页已互相链接。

## 验证

- 先写测试：`docs-nav-list.test.tsx` 新增「API 说明页在方法列有图标」用例并把工具组第一项改为「概览」，修改前 2 个失败，修改后通过。
- `bunx vitest run src/features/docs`：13 文件 138 用例通过（含站内链接 / 锚点检查）；`bun check -b` 无类型错误；`oxlint` 无 error。
- 浏览器检查侧栏：鉴权、错误码图标与 GET/POST 标签同列对齐；开始使用组剩快速开始、连接自检、常见问题与排错。
- Go 端 SEO 注入与 sitemap 的页面列表来自构建期清单，无需改动。

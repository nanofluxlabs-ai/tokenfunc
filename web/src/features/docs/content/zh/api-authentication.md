所有模型接口都需要在请求头里携带本站的密钥。密钥在 [API 密钥](/keys) 创建。

## Bearer 令牌（推荐）

适用于全部接口：

```http
Authorization: Bearer {{apiKey}}
```

密钥前面的 `sk-` 可写可不写。

## 其他写法

为了兼容各家 SDK，部分接口还接受以下写法：

| 请求头 / 参数                | 适用接口                                           | 说明                                                           |
| ---------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| `x-api-key: {{apiKey}}`      | `/v1/messages`、`/v1/models`                       | Anthropic SDK 的写法，通常搭配 `anthropic-version: 2023-06-01` |
| `x-goog-api-key: {{apiKey}}` | Gemini 原生接口 `/v1beta/models/...`、`/v1/models` | Google SDK 的写法                                              |
| `?key={{apiKey}}`            | Gemini 原生接口 `/v1beta/models/...`、`/v1/models` | 放在网址里，容易被日志记录，不推荐                             |

```bash
# Anthropic 格式
curl {{baseUrl}}/v1/messages \
  -H "x-api-key: {{apiKey}}" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{model:claude}}", "max_tokens": 256, "messages": [{"role": "user", "content": "你好"}]}'
```

## 密钥的限制项

创建或编辑密钥时可以设置以下限制，超出限制的请求会被拒绝：

| 限制      | 超出时                                                           |
| --------- | ---------------------------------------------------------------- |
| 额度上限  | 密钥额度用完后返回 `401`                                         |
| 可用模型  | 调用未授权的模型返回 `403`                                       |
| IP 白名单 | 来自其他 IP 的请求返回 `403`                                     |
| 过期时间  | 过期后返回 `401`                                                 |
| 分组      | 只能使用该分组下的模型；分组对你的账户不可用或已停用时返回 `403` |

## 安全建议

- 密钥等同于付款凭证，持有者可以消耗你的余额。
- 每个工具或项目单独一把密钥，并按需设置额度上限。
- 不要把密钥写进前端代码、提交到代码仓库或发到聊天群里。在浏览器里调用请经过你自己的后端转发。
- 怀疑泄露时，立即在 [API 密钥](/keys) 删除或禁用该密钥。

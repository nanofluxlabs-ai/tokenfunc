# 概览页「每日消耗汇总」表格列间距与占比轨道可见性

- 日期：2026-11-22
- 分支：main
- PR：
- 关键 commit：

## 背景

用户反馈：控制台 › 常规 › 概览 的「每日消耗汇总」表格中，「Token」与「主力模型」两列文字挨在一起；占比进度条在 0% 时看不清。

## 变更

- 前端 `features/dashboard/components/personal/daily-summary-table.tsx`：
  - 第一版给「主力模型」加 `ps-10` 留白，用户反馈间距仍与其它列不一致，已撤回；
  - 列顺序改为 日期 | 主力模型 | 请求数 | 费用 | Token | 占比：文本列在左、数字列在右；
  - 表格 `table-fixed` 等分列宽（`min-w-[40rem]`，窄屏由表格容器横向滚动），去掉占比列 `w-40`，占比表头右对齐；
  - 占比进度条固定 `w-24` 靠右，轨道由 `bg-muted` 改为 `bg-foreground/10`。

## Bug 根因

- 表格除「占比」外无列宽，自动布局下右对齐的 Token 列与左对齐的主力模型列在列边界两侧相贴，中间只有单元格内边距。相邻列对齐方向不同时，间距只能是内边距，加留白也无法与「右对齐→右对齐」的整列宽间距一致，必须让同向对齐的列相邻。
- 卡片底色与 `bg-muted` 几乎相同，进度条无填充时轨道与背景融为一体。

## 验证

- `bun check -b` 无类型错误；`oxlint`、`oxfmt --check` 该文件通过。
- 浏览器（5173 → API 3010，root）暗色主题：请求数 / 费用 / Token / 占比 各列等距，0% 行可见灰色轨道，进度条不再贴住 Token 数字。

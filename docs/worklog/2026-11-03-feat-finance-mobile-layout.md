# 财务中心移动端适配：指标卡两列、筛选栏网格化

- 日期：2026-11-03
- 分支：main
- PR：
- 关键 commit：

## 背景

黑鹰反馈财务中心在手机上太占空间：经营看板 8 个指标卡一行一个；用户消耗、模型消耗、企业账单的查询条件各占 3–5 行，用户消耗的用户名输入框独占一整行。要求只做移动端适配，信息不能减少。

## 变更

只改 Tailwind 类，移动优先：基础类是手机端网格，`sm:` 起恢复原来的单行 flex，桌面端布局不变。

- 经营看板：指标卡网格基础改为 `grid-cols-2`，手机端 8 个指标占 4 行；共享的 `MetricCard` 不动。
- 用户消耗：两列网格，「用户名 / 用户 ID + 分组」一行，「查询 + 重置」一行（3 行 → 2 行）。
- 模型消耗：六栏网格，「模型名 + 用户名 + 分组」各占 2 栏一行，两个按钮各占 3 栏一行（3 行 → 2 行）。
- 企业账单：两列网格，「企业名称 + 账单号」「状态 + 搜索 / 重置」「合计 + 开票方信息设置」三行（4–5 行 → 3 行）；后两组用 `sm:contents` 在桌面端回到原 flex 流。
- 新增 `web/src/features/finance/lib/filter-layout.ts` 的 `FILTER_BAR_BUTTON_CLASS`：手机端按钮撑满格子，英文等长文案允许折行而不溢出，用户消耗与模型消耗共用。

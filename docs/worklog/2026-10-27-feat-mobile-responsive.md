## 背景

黑鹰要求审查 tokenfunc 在 new-api 上新增的所有界面（相对上游 v1.0.0-rc.45），做一次移动端响应式适配，重点是信息结构与布局，交互简洁、信息清晰；并反馈登录页手机首屏全是品牌信息、登录表单被挤到屏幕底部。

拍板项（计划批准即确认）：
- 分层标准：A 对外（认证页、首页、文档、关于页）与 B 客户（企业控制台 6 页、推广中心、个人对账）调整组件顺序、取舍、卡片化；C 内部后台（财务中心、报价单、日志归档、渠道用量、推广人、企业线索、用户管理企业页签）只保证不破版、可用。
- 手机上日期 / 筛选控件统一收进「筛选」底部抽屉，并随内容滚动（不再常驻页头）。
- 企业概览手机顺序：账户 → 待办 → KPI → 快捷入口 → 趋势 → 模型 Top5。
- 账单详情多条说明合并为一条可展开摘要；宽表手机隐藏次要列（token 拆分、缓存、单价、倍率）。
- 团队管理手机用团队切换替代左侧团队列表（实施时改为弹出完整 TeamPanel，见下）。

## 变更

适配手段优先复用上游：DataTablePage 的移动卡片（列 meta mobileTitle / mobileBadge / mobileHidden / label）、StatCard compactMobile、Sheet / Popover / Collapsible 原语、Tailwind sm 断点（640px，与 DataTablePage 一致）。

  - 文档：参数表手机隐藏类型 / 默认值（挪到参数名下）；四张表的说明改用 `DocsTableText`（text 属性），不再被 StaticDataTable 截成单行；手机目录入口吸顶并显示当前页标题。
  - 关于页：只改二开的 BrandAbout 内边距；上游 URL / HTML 分支不动。
- B 客户（共用）

- B 客户（逐页）
  - 概览：快捷入口手机前置；KPI 与报表合计卡手机两列紧凑；账户卡大金额可换行；卡头页签窄卡片换到标题下（`lib/card-layout.ts` 的 CARD_ACTION_STACKED，按卡头容器宽度）；排行图标签手机收窄。

  - 密钥：复制按钮手机 32px、启停 / 编辑 36px，批量操作栏可换行。
- C 后台
  - 日志归档、企业成员抽屉、企业线索补卡片 meta。
  - MetricTooltip 触屏（hover: none）改为点按 Popover；「悬停查看」文案改为「悬停或点按」（七语言）。
  - 渠道用量展开明细 sticky 钉在视口内；报价单配置页签可换行、预览手机内边距 12px。
- i18n：新增 `Switch team`、`{{count}} more notes`、`Hide notes`，七个 tokenfunc locale 同步。

### 追加：消费明细卡片缺字段名（黑鹰验收反馈）

- 现象：企业账单详情、对账「消费账单」的消费明细在手机卡片上只显示 1,000 / 0 / 500 等裸数字，看不出是输入、缓存还是输出。
- 根因：`usage-detail-table.tsx` 的数字列由 `numeric()` 构造，表头是函数，没写 `meta.label`，卡片取不到字段名；第一轮只按清单补了推广中心与个人对账，漏了这张共用表。
- 修复：`numeric()` 统一带 `meta.label`；金额设 `mobileBadge` 放到卡片右上角；数字在卡片里左对齐（桌面仍右对齐）。脚本扫了全部二开列表里「函数表头且无 label」的列，一并补上模型消费、用户消费、推广人列表；上游 channels / users 文件与手机显示表格的渠道用量不动。
- 验证：新增 `usage-detail-table.test.tsx`（换回旧代码时字段名用例失败、恢复后通过）；浏览器 390px 下账单详情与对账消费账单两处卡片均显示「输入 tokens / 缓存命中 / 缓存写入 / 输出 tokens」。

### 追加：用量报表按日表限高（黑鹰反馈）

- 现象：查 10.1～10.27 时按日表 27 行全部展开，下面的按模型 / 按归属要拉到表底才看得到。第一轮为避免手机嵌套滚动去掉了手机上的 max-h-96；桌面虽有 max-h-96，但表格自带的横滑容器（table-container）是独立滚动层，表头也不固定。
- 修复：表格关掉 `withContainer`，由 StaticDataTable 根节点 `max-h-[460px] overflow-auto` 同时负责纵横滚动（表头 40px + 7 行 × 60px），表头行 `[&>th]:sticky top-0`；手机与桌面一致，区间 ≤7 天时按实际高度。
- 验证：390px 与 1280px 下 27 天区间均可见 7 行、表内滚动、滚动后表头仍贴顶，页面无横向溢出；`usage-panel.test.tsx` 补限高与 sticky 表头用例。

### 追加：手机登录页视觉（黑鹰反馈）

- 现象：表单贴顶、下方约 1/3 空白，整页纯色显得太素。贴顶是第一轮为解决「表单被挤到底部」有意为之。
- 决定（黑鹰选定）：不做插画，把已有品牌极光铺满手机全屏；只改 lg 以下，桌面不变。
- 修改 `auth-layout.tsx`：
  - lg 以下在整页底层加 fixed 极光（新增 `.tf-aurora-page`，光斑落在顶部和右下）。
  - Logo 栏改为透明。
  - 表单包进半透明毛玻璃卡（`bg-background/85` + `backdrop-blur-xl`），卡片在页面里垂直居中。
  - 卡片下方加一行信任信息：登录页显示三项指标，注册页显示三条卖点。
  - 卡底色选 `bg-background` 而不是 `bg-card`，是为了和上游 `oauth-providers.tsx` 分隔线文字的实心底色一致，这样不用改上游文件。
- 验证：
  - 390×844 暗色：卡片 127～691px，信任条 715～753px，无横向溢出。
  - 375×667 亮色注册页：内容超出一屏时从顶部排开。

  - reduced-motion 下极光不动画。

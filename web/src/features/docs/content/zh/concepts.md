接入前花两分钟弄清下面五个概念，可以少踩大部分坑。

## 接口地址

接口地址（Base URL）是所有请求的公共前缀：

:::base-url
:::

不同工具对这个地址的写法要求不同，这是接入失败最常见的原因：

| 工具使用的协议                 | 填写方式             | 示例                              |
| ------------------------------ | -------------------- | --------------------------------- |
| OpenAI 兼容（大多数工具、SDK） | 地址 + `/v1`         | `{{baseUrl}}/v1`                  |
| Anthropic（Claude Code 等）    | 只填地址，不带 `/v1` | `{{baseUrl}}`                     |
| 要求填完整路径的工具           | 地址 + 完整接口路径  | `{{baseUrl}}/v1/chat/completions` |

工具会在你填的地址后面自动拼接路径。多写或少写 `/v1`，最终请求的路径就会变成 `/v1/v1/...` 或缺一段，返回 404。

## 密钥

密钥（API Key）以 `sk-` 开头，代表你的账户身份，持有密钥的人可以消耗你的余额，请像密码一样保管：

- 每个工具或项目单独创建一把，泄露时只需删除那一把。
- 不要把密钥提交到代码仓库，不要在截图、群聊里暴露。
- 可以在 [API 密钥](/keys) 里为密钥限制额度、可用模型、IP 和有效期。

请求时把密钥放在请求头里，最常用的写法是 `Authorization: Bearer {{apiKey}}`，其他写法见 [鉴权](/docs/api-authentication)。

## 分组

分组决定一把密钥能用哪些模型、按什么倍率计费。创建密钥时可以选择分组，不同分组的可用模型和价格在 [模型广场](/pricing) 里可以筛选查看。

如果某个模型在模型广场里能看到、但调用时提示无权访问，通常是密钥所在的分组不包含这个模型。

## 模型名

请求里的 `model` 字段必须和本站的模型名**完全一致**，大小写和连字符都不能错。获取方式：

- 在 [模型广场](/pricing) 查看并复制。
- 调用 [模型列表](/docs/api-models) 接口，返回的就是当前密钥可用的模型。

部分模型支持在名字后面加后缀来控制思考强度，例如 `-thinking`、`-high`，详见 [思考模型](/docs/examples-reasoning)。

## 计费

按实际用量从余额中扣费，大多数文本模型按 Token 计费，输入和输出分别定价；部分模型按次计费。每个模型的价格见 [模型广场](/pricing)。

- 用量和扣费明细在控制台的「使用日志」里逐条可查。
- 命中提示词缓存的输入按更低的缓存价计费，见 [提示词缓存](/docs/examples-prompt-caching)。
- 余额不足时请求会被拒绝，充值后立即恢复。

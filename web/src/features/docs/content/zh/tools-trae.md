Trae 是字节跳动推出的 AI 编辑器，支持在设置里添加「自定义模型」，OpenAI 兼容和 Anthropic 两种格式都能用。国内版和国际版的操作相同。

- 协议：OpenAI 兼容，或 Anthropic
- 地址：OpenAI 兼容填 `{{baseUrl}}/v1`，Anthropic 填 `{{baseUrl}}`
- 模型：任意，例如 `{{model}}`

:::tip
请先把 Trae 升级到最新版本。较早的版本不会自动补全接口路径，按本教程填写会报错。
:::

:::steps
### 打开添加模型窗口

在 Trae 中打开 **设置 → 模型**，点击 **添加模型**。也可以在对话框的模型列表底部点击「添加模型」。

![Trae 设置中的模型页面，「添加模型」按钮位置](todo:tools/trae-models.png)

### 选择自定义模型和接口格式

服务商选择 **自定义模型**，然后在 **API 格式** 中选择：

- **OpenAI Chat Completions 格式**：用于 GPT、DeepSeek、GLM、Kimi、Gemini 等模型。
- **Anthropic Messages 格式**：用于 Claude 模型。

### 填写地址、模型和密钥

确认「完整 URL」开关处于**关闭**状态，然后填写：

| 字段           | OpenAI Chat Completions 格式 | Anthropic Messages 格式 |
| -------------- | ---------------------------- | ----------------------- |
| 自定义请求地址 | `{{baseUrl}}/v1`             | `{{baseUrl}}`           |
| 模型 ID        | `{{model}}`                  | `{{model:claude}}`      |
| API 密钥       | `{{apiKey}}`                 | `{{apiKey}}`            |

模型展示名称可以随意填写，方便自己辨认。

如果你打开了「完整 URL」开关，需要填写完整路径：OpenAI 格式填 `{{baseUrl}}/v1/chat/completions`，Anthropic 格式填 `{{baseUrl}}/v1/messages`。

![Trae 自定义模型表单：API 格式、请求地址、模型 ID、API 密钥已填写，完整 URL 开关为关闭](todo:tools/trae-custom-model.png)

### 按需调整高级配置

展开 **高级配置**，按模型实际能力设置上下文窗口、是否支持图片输入、是否开启思考模式等。不确定时保持默认即可。

### 添加并验证

点击 **添加模型**。Trae 会实际调用一次接口检查配置：成功后模型出现在列表中；失败时会显示错误信息，按下面的表格排查。

添加成功后，在对话框的模型列表中选择它，发一句话确认能收到回复。
:::

## 常见问题

| 现象                                | 原因与处理                                                                             |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| 添加时报 404                        | 地址写法和「完整 URL」开关不匹配。开关关闭时只填到 `/v1`（或根地址），打开时填完整路径 |
| 添加时报 401                        | 密钥填错或额度用完，到 [API 密钥](/keys) 检查                                          |
| 模型不存在 / 无可用渠道             | 模型 ID 和本站模型名不一致，从 [模型广场](/pricing) 复制                               |
| 添加成功但对话里看不到              | 模型在列表中被禁用了，在设置 → 模型中启用它                                            |
| Claude 模型用 OpenAI 格式也能用吗？ | 可以，本站会自动转换；但用 Anthropic 格式时思考、缓存等能力更完整                      |
